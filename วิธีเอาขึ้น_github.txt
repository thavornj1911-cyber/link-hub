==========================================================
📌 วิธีนำ LinkHub ขึ้นใช้งานออนไลน์บน GitHub Pages (ฟรีตลอดชีพ)
==========================================================

1. เข้าเว็บ https://github.com แล้วล็อกอิน
2. กดปุ่มสีเขียว "New" เพื่อสร้าง Repository ใหม่
   - ช่อง Repository name: ตั้งชื่อ เช่น link-hub
   - เลือกเป็น: Public
   - กดปุ่ม "Create repository" ด้านล่าง

3. อัปโหลดไฟล์ขึ้น GitHub:
   - ในหน้าใหม่ที่ขึ้นมา ให้มองหาข้อความ "uploading an existing file" แล้วกดเข้าไป
   - ลากไฟล์ "index.html" จากโฟลเดอร์นี้ไปวาง
   - กดปุ่มสีเขียว "Commit changes" ด้านล่าง

4. เปิดใช้งาน GitHub Pages:
   - ไปที่แท็บ "Settings" (รูปเฟืองด้านบน)
   - เมนูด้านซ้ายเลือกหัวข้อ "Pages"
   - ในส่วน Branch ให้เลือก "main" และเลือกโฟลเดอร์ "/ (root)"
   - กดปุ่ม "Save"

5. รอประมาณ 30 วินาที จะมีลิงก์สีเขียวขึ้นมา เช่น:
   https://<ชื่อผู้ใช้ของคุณ>.github.io/link-hub/

สามารถนำลิงก์นี้ไปเปิดใช้งานบนมือถือ (iPhone/Android) หรือแชร์ให้เพื่อนได้ทันที!
(ถ้าเปิดในคอมตอนนี้ สามารถดับเบิ้ลคลิกไฟล์ "คลิกเปิดแอป.bat" หรือ "index.html" ได้เลย)
