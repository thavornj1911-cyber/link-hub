# 🔖 LinkHub - Web App รวมลิ้งค์ & จดโน้ตท่องเที่ยว/ของกิน (รองรับ GitHub Pages)

เว็บแอปพลิเคชันสำหรับจัดเก็บลิ้งค์ต่างๆ จากโซเชียลมีเดีย เช่น **Facebook, TikTok, YouTube, Instagram, X, Lemon8, Google Maps** พร้อมระบบแยกหมวดหมู่การท่องเที่ยว/ของกิน (เช่น ของกินโคราช, เที่ยวเขาใหญ่, เที่ยวชลบุรี-ระยอง, เที่ยวฟุกุโอกะ) และระบบเขียนคอมเมนต์/จดโน้ตในแต่ละลิ้งค์

> 💡 **ใช้งานได้ 100% บน GitHub Pages:** ไม่ต้องใช้ Render, ไม่มีเซิร์ฟเวอร์หลับ (No Cold Start), โหลดเร็วทันที และฟรีตลอดชีพ!

---

## 🌐 วิธีนำขึ้น GitHub Pages ใช้งานออนไลน์ (ทำตาม 4 ขั้นตอนนี้)

### ขั้นตอนที่ 1: สร้าง Repository บน GitHub
1. เข้าไปที่ [GitHub](https://github.com) แล้วกด **New repository**
2. ตั้งชื่อ Repository เช่น `link-hub`
3. เลือกระดับเป็น **Public** (เพื่อให้ใช้ GitHub Pages ฟรีได้) แล้วกด **Create repository**

### ขั้นตอนที่ 2: อัปโหลดไฟล์ขึ้น GitHub
- คุณสามารถลากไฟล์ [`index.html`](file:///C:/Users/jkc/.gemini/antigravity/scratch/link-hub/index.html) และไฟล์ในโฟลเดอร์นี้ไปวางบนหน้าเว็บ GitHub โดยตรงผ่านปุ่ม **Upload files** หรือใช้ Git Push ขึ้นไป

### ขั้นตอนที่ 3: เปิดใช้งาน GitHub Pages
1. ในหน้า Repository ของคุณบน GitHub ไปที่แท็บ **Settings** (รูปเฟืองด้านบน)
2. เมนูด้านซ้ายเลือก **Pages**
3. ตรงส่วน **Branch**:
   - เลือก Branch เป็น `main`
   - เลือกโฟลเดอร์เป็น `/ (root)`
4. กดปุ่ม **Save**

### ขั้นตอนที่ 4: เข้าใช้งานได้ทันที!
รอประมาณ 30 วินาที GitHub จะแสดงแถบสีเขียวพร้อมลิงก์เว็บของคุณ เช่น:
```text
https://<ชื่อผู้ใช้ของคุณ>.github.io/link-hub/
```
สามารถนำลิงก์นี้ไปเปิดบน **iPhone, Android, แท็บเล็ต หรือคอมพิวเตอร์** ได้จากทุกที่ทั่วโลกทันที!

## ✨ ฟีเจอร์ทั้งหมดของระบบ

1. **แยกแพลตฟอร์มโซเชียลอัตโนมัติ (Platform Auto-Detection):**
   - รองรับ **Facebook, TikTok, YouTube, Instagram, X, Lemon8, Google Maps, เว็บทั่วไป**
   - ตรวจจับแพลตฟอร์มอัตโนมัติจาก URL ที่วาง พร้อมดึงรูปและชื่อเรื่องให้อัตโนมัติ
2. **จัดหมวดหมู่ท่องเที่ยว & ของกิน (Custom Categories):**
   - มีหมวดสำเร็จรูปพร้อมใช้งาน: `🍜 ของกินโคราช`, `⛰️ เที่ยวเขาใหญ่`, `🏖️ เที่ยวชลบุรี-ระยอง`, `✈️ เที่ยวฟุกุโอกะ`, `☕ ที่พัก & คาเฟ่`
   - กดปุ่ม **"+ หมวดใหม่"** เพื่อสร้างหมวดของตัวเอง เลือกอีโมจิ และสีประจำหมวดได้ไม่จำกัด
3. **ระบบคอมเมนต์ & จดโน้ต (Comments & Notes):**
   - พิมพ์โน้ตด่วนบนการ์ดแต่ละใบได้ทันที (เช่น "ร้านเปิด 9:30 น. เมนูเด็ดคือต้มยำ", "ต้องโทรจองก่อน")
   - กดดูประวัติความคิดเห็นแบบ Timeline พร้อมระบุวันเวลาที่บันทึก
4. **ดูวิดีโอ YouTube ในตัว (In-App Video Player):**
   - ถ้าเป็นลิ้งค์ YouTube สามารถกดปุ่ม Play เพื่อดูวิดีโอในหน้าเว็บได้ทันที
5. **ปักหมุดรายการโปรด (⭐ Favorite Pin):**
   - กดดาวเพื่อปักหมุดลิ้งค์ที่ชอบไว้บนสุด
6. **ค้นหาแบบเรียลไทม์ (Live Search):**
   - ค้นหาได้ทั้งจากชื่อ, รายละเอียด, แฮชแท็ก, หมวดหมู่ และข้อความในคอมเมนต์
7. **สำรองและกู้คืนข้อมูล (Backup & Restore):**
   - ข้อมูลจะบันทึกอยู่ในเบราว์เซอร์อัตโนมัติ (localStorage)
   - สามารถกดปุ่ม **สำรองข้อมูล (JSON)** เพื่อดาวน์โหลดไฟล์เก็บไว้ และนำไปอัปโหลดใส่ในมือถือหรืออุปกรณ์อื่นได้ทุกเมื่อ
